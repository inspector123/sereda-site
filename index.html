OMP Companion

A phone app for OMP, an open-source coding agent forked from Pi. The app drives an agent session running on a desktop computer: you send prompts, watch the agent work and steer it from your phone, while the code and tools stay on the computer. In this recording the model is Qwen, served locally, with no cloud model involved.

Phone app → encrypted relay → Pi extension → OMP session

The recording

A single prompt from the app to Qwen3.8-Flash-Next, recorded on an Android emulator against a test server. The video is trimmed and captioned, with no other edits.

The demo itself was produced by a coding agent: from a written brief, it set up the test server and emulator, signed in, ran the prompt, recorded the screen and built this page.

How it works

The app starts from the open-source Happy Coder client. I replaced its backend with a Pi extension I wrote, so it speaks to OMP directly.

  • A small wrapper runs OMP in a terminal on the computer and keeps a connection to a self-hosted relay. Traffic between the app and the computer is end-to-end encrypted.
  • The extension runs inside OMP and talks to the wrapper over a local socket.
  • Prompts from the phone enter the session through pi.sendUserMessage.
  • OMP's structured events (text, reasoning, tool calls and subagents) stream back to the phone, so nothing is scraped from the terminal.
  • Sessions started from the phone run in herdr on the computer, so the same session can be attached and continued at the desk.
  • Sessions started on the computer appear in the app immediately. It is one session either way, so work moves between phone and desk without a handoff.
