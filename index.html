The phone app

One prompt from the phone to Qwen3.8-Flash-Next running on my GPUs, about 94 tok/s. Unedited, 73 seconds, recorded on an Android emulator against a separate test server.

How it works

The app is a fork of Happy Coder. I replaced the backend with an OMP extension.

  • On my computer a small wrapper runs OMP in a terminal and keeps a connection to a relay server I host.
  • The extension runs inside OMP and talks to the wrapper over a local socket.
  • Prompts from the phone go into the session with pi.sendUserMessage.
  • OMP's own events (text, reasoning, tool calls, subagents) go back to the phone, so nothing is read off the terminal.
  • Because it's a normal OMP session, I can open the same one at my desk.
